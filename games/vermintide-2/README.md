# Warhammer: Vermintide 2

The game script reference is pinned as a Git submodule at `external/Vermintide-2-Source-Code/`. The initial pin is the [6.13.0 script snapshot](https://github.com/InfusedChooch/Vermintide-2-Source-Code/commit/93dea911a4cc464a0eb51cfdc3a443297bfc4550), dated October 13, 2026.

## Get the reference

From the hub root, run:

```powershell
git submodule update --init -- games/vermintide-2/external/Vermintide-2-Source-Code
```

When updating the pin, record the game patch that the new commit represents.
