Boneforge Wilds 0.1.0 for Monster Hunter Wilds on Windows

Downloads for a clean install on Windows (non-VR)
1. Official REFramework for Monster Hunter Wilds: open the release page
   below and select MHWILDS.zip under Assets.
   https://github.com/praydog/REFramework/releases/latest
2. Boneforge Wilds menu: boneforge-wilds-public-v0.1.0.zip (this archive).
   https://github.com/InfusedChooch/boneforge-menu-hub/releases/tag/wilds-public-v0.1.0

If upgrading from another GHL QOL edition, close the game and follow that
edition's removal instructions first. Back up any existing
reframework/autorun/GHLQOL folder outside the game folder before merging.

Install
1. Close Wilds. In Steam, right-click Monster Hunter Wilds and select
   Manage > Browse local files. Keep the folder with MonsterHunterWilds.exe open.
2. Open MHWILDS.zip. Copy dinput8.dll directly beside MonsterHunterWilds.exe.
3. Open the Boneforge ZIP. Copy its entire reframework folder into that same
   game folder. Merge folders if prompted. Compare the result with this layout:

   Monster Hunter Wilds/
   |-- MonsterHunterWilds.exe
   |-- dinput8.dll                      (from MHWILDS.zip)
   `-- reframework/                     (from the Boneforge ZIP)
       `-- autorun/
           |-- BoneforgeWilds.lua
           `-- GHLQOL/                  (eight Lua modules)

4. Launch Wilds. Press Insert (the default REFramework overlay key), expand
   Script Generated UI, and open BoneforgeWilds. Choose a page. Load your
   hunter to use actions that require an active character.

Pages
Meals, Buffs, Extras, Positions and Map. Settings are saved by REFramework
in reframework/data/GHLQOL-gameplay.json. Position bookmarks and map pins
last for the current scene and session.

Uninstall
Close the game. Remove reframework/autorun/BoneforgeWilds.lua and the
eight files listed under reframework/autorun/GHLQOL in this ZIP. Restore
your previous copies if you backed them up. You can keep the gameplay
settings file for a later install.
